# Анастасия Чепкасова — сайт-визитка

Консультант по планировке, декору и текстильному оформлению интерьера.

Статический сайт: один файл `index.html` и папка `img/` с фотографиями. Сборка не нужна, откройте `index.html` в браузере.

Разделы: Главная, Работы, Этапы, Прайс, Контакты.

## Публикация на GitHub Pages

Settings → Pages → Source: Deploy from a branch → ветка `main`, папка `/ (root)`.
